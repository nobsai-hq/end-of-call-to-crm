End of call to CRM, no duplicates

A free n8n template by No BS AI. When an AI phone call ends, the result lands in your CRM once. A retried webhook with the same call ID does not create a second contact.

This page is a browser sandbox Nothing is sent to a server

This page does not write to GoHighLevel and it does not collect personal data. The real workflow is the n8n file in the GitHub repo. I have not yet run that workflow against a live Vapi number or a live GHL sub-account.

What it does

  1. A webhook receives the end-of-call event and answers HTTP 200 right away, so Vapi or Twilio stop retrying.
  2. The workflow reads a call ID, the caller number, and a short summary.
  3. If that call ID was already seen, it skips the CRM write.
  4. If it is new, it can upsert a GoHighLevel contact by phone and tag it.

It accepts a Vapi end-of-call-report, a Twilio hangup or status callback, or a simple test payload.

How it works

  1. Import workflow.json into n8n.
  2. Edit the Settings node. Add a Header Auth credential for GHL if you want a real CRM write.
  3. Turn the workflow on and copy the Production URL.
  4. Paste that URL into Vapi (assistant server URL) or Twilio (status callback).
  5. Send the same call ID twice. The second one should be skipped.
